Game Setup

Rule Description

Normal:
Reversi (Othello) standard rules. Black goes first, white goes second, alternately placing stones on the board. The player with the most stones at the end wins. If there are no more valid moves, the player with the most stones wins.
Handicap (1):
Add a black stone to the top-left corner and start the game.
Handicap (2):
Add black stones to the top-left and bottom-right corners and start the game.
Handicap (3):
Add black stones to the top-left, bottom-right, and top-right corners and start the game.
Handicap (4):
Add black stones to all four corners and start the game.
Variant (Negative):
If a stone is placed in a corner, all stones in the opposite corner will be flipped. This can be a double-edged sword, as it can be easy to overplay the corner.
Variant (Revolution):
If a stone is placed in a corner, all stones in the other corner will be flipped. This can be a double-edged sword, as it can be easy to overplay the corner.

※Handicap games always start with white as the first player.

Normal:
標準ルール
黒が先手、白が後手で交互に石を置いていき、最後に数が多いほうが勝ちになります。相手の石を挟める場所が1つもない場合はパスになります。
Handicap (1):
ハンデ戦（1子局）
左上の隅に黒石を追加して対局を開始します。
Handicap (2):
ハンデ戦（2子局）
左上と右下の隅に黒石を追加して対局を開始します。
Handicap (3):
ハンデ戦（3子局）
左上と右下、右上の隅に黒石を追加して対局を開始します。
Handicap (4):
ハンデ戦（4子局）
四隅全てに黒石を追加して対局を開始します。
Variant (Negative):
変則ルール（最弱）
通常とは逆に、終局時に「石が少ない方」が勝ちとなります。初期配置はノーマルと同じです。自分の石をいかに消すか、相手に取らせるかが重要です。
Variant (Revolution):
変則ルール（革命）
隅（角）に石を置くと、他の隅にある石がすべて裏返るルールです。安易に隅を狙うと痛い目に遭うかもしれません。

※ハンデ戦では常に白が先手になります。
