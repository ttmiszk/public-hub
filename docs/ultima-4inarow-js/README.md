# Ultima 4 in a Row - Browser Edition

**Version 0.1.0**

ブラウザで遊べるスタイリッシュな重力付き四目並べ（Connect 4）ゲームです。  
AI対戦、2人対戦に対応し、モダンなUIと心地よいアニメーション・サウンド演出を備えています。

## 概要

Android／UWP版「Ultima 4 in a Row」の強力なゲームロジックを移植し、HTML/CSS/JavaScriptのみで完全に再構築しました。  
「Neumorphism（ニューモーフィズム）」を取り入れたデザインと、物理挙動を意識したチップ落下アニメーションが特徴です。

## 特徴

### 🎮 ゲームプレイ
- **多彩なモード**: 1人プレイ (vs AI)、2人プレイ、AI同士の観戦
- **強力なAI**: Alpha-Beta法とMove Orderingを搭載した10段階のレベル設定
- **便利機能**: Undo（待った）、先攻後攻の自動交代オプション

### 🎨 ビジュアル & 演出
- **選べるテーマ**:
    - **Light**: 落ち着いたサンドベージュのデフォルトテーマ
    - **Dark**: 目に優しいダークフラットデザイン
    - **Pop**: 鮮やかなブルーとピンクのハイコントラストテーマ
- **リッチなアニメーション**:
    - 物理挙動を模したチップの落下と着地（バウンド・ガタつき）
    - 勝利時のブレス（呼吸）演出
    - リアルな透過ボード表現
- **サウンド**: 心地よい着手音とファンファーレ（ON/OFF可能）

### 📱 技術仕様
- **レスポンシブ**: PC、タブレット、スマートフォンに対応
- **PWA Ready**: メタタグ設置済み（ホーム画面に追加可能）
- **サーバレス**: 静的ファイルのみで動作（GitHub Pages等で即公開可能）

## 遊び方

1. `index.html` をブラウザで開きます。
2. 設定画面で「プレイヤー（Human/AI）」「レベル」「先攻後攻交代」を選択し、Start Gameを押します。
3. 盤面の列をクリック/タップしてチップを落とします。
4. 縦・横・斜めのいずれかにチップを4つ並べた方が勝利です。

## 動作環境

- モダンブラウザ（Chrome, Firefox, Edge, Safari の最新版）
- JavaScript有効
