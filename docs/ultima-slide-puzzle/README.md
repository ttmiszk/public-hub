# Ultima Slide Puzzle (v1.0.0)

ブラウザで動作するサーバレスのスライドパズルゲームです。

---

## 遊び方

1. **ゲームの開始**:
   - `src/index.html` をお好みのブラウザ（Chrome, Edge, Safari, Firefox等）で開きます。
   - 画面下部のコントロール行から、盤面のサイズ（3x3 〜 7x7）を選択します。
   - `Start` ボタンを押すとパズルがシャッフルされ、タイマーと手数の計測が始まります。
   - タイルをクリック、またはキーボードの矢印キー、もしくは W, A, S, D キーでサクサクと滑らかにスライドさせることができます。

2. **画像で遊ぶ**:
   - `Set Image` ボタンからお好きな画像を読み込み、`Apply` をクリックすると、ゲーム中の配置を維持したままパズルに画像が適用されます。
   - 選択した画像はすべてブラウザ上のローカル環境（メモリ内）のみで処理されます。外部サーバー等へ送信・アップロードされることは一切ありません。
   - 画像を解除して数字のみのパズルに戻したい場合は、画像選択画面から `Remove Image` をクリックして確定します。
   - 画像パズルを遊ぶ際、`Show Numbers` の ON/OFF 切り替えにより、ガイド用の数字を表示・非表示できます。

3. **クリア**:
   - タイルをスライドさせ、正しい順序（右下が空欄）に並べ替えたらゲームクリアです！
   - クリア画面の `Close` ボタンを押すと、完成した画像をゆっくり眺めることができます。

---

## 動作環境

- **対応ブラウザ**: 各種モダンブラウザ（Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari の最新版）
- **動作要件**: JavaScript 有効化
