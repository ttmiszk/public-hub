# Ultima Shooter (v0.1.1)

Webブラウザ上で動作する、Three.js を用いた 3D縦スクロールシューティングゲームです。

© 2026 Ultima Architect Inc.

---

## 概要
HTML/CSS/JavaScript、Three.js (r128)、および Web Audio API を使用して構築されています。  
外部のビルドツール（Node.js/Webpack等）やローカルサーバーの構築は不要です。`src/index.html` をブラウザ（Google Chrome, Firefox, Edge等）で開くだけですぐにプレイ可能です。

---

## 主な特徴
- **ピュアフロントエンド**: ビルド不要の生 JavaScript (ES6+) モジュール構成。
- **Web Audio API プロシージャルサウンド**: BGMおよび効果音をすべてプログラム処理でリアルタイム合成。外部音声ファイル不要の軽量・即時ロード設計。
- **ポストプロセッシング視覚効果**: Three.js の UnrealBloomPass による美しいネオン光彩グラフィック。
- **周回（ループ）システム**: 全3ステージをクリアすると難易度とスピードが上昇した状態で次の周回（LOOP）へ突入。
- **プロシージャル洞窟生成**: シード値に基づくチューブ状の洞窟地形を動的に生成し、壁面判定を処理。
- **ローカルランキング機能**: LocalStorage を使用してハイスコア TOP 10（周回数・ステージ数・日時含む）を保存・閲覧可能。
- **ObjectPool パターン**: 弾薬・敵機・エフェクトパーティクル等を再利用し、ガベージコレクション(GC)によるフレーム落ちを防止。
- **可変 FPS / デルタタイム対応**: リフレッシュレート（60Hz/144Hz/240Hz等）に関わらず均一なゲーム速度を維持。
- **充実のデバッグパネル**: ステージ選択、周回数変更、無敵モード、洞窟シード設定等のテスト機能を標準搭載。

## 遊び方

### 起動方法
1. 本リポジトリをローカルにクローンするかダウンロードします。
2. `src/index.html` をお使いのブラウザで直接開いてください。

---

### 操作方法
本ゲームは **キーボード** および **ゲームパッド（XInput対応コントローラー等）** に対応しています。

#### キーボード操作
- **[↑] [↓] [←] [→]** または **[W] [A] [S] [D]**: 自機の移動
- **[Space]**: ショット発射 / メニュー項目の決定
- **[Enter]**: メニュー項目の決定
- **[Esc]**: ポーズ / ポーズ解除 / キャンセル

#### ゲームパッド操作
- **左スティック** または **十字キー (D-Pad)**: 自機の移動
- **A ボタン** または **RT (R2)**: ショット発射 / メニュー項目の決定
- **START ボタン**: ポーズ / ポーズ解除
- **SELECT ボタン**: デバッグパネルの開閉

## ステージ構成 & 周回システム

ゲームは全3ステージで構成され、各ステージで一定の敵撃破ポイント (POINT) に達するとボス接近およびステージクリアとなります。

1. **STAGE 1: SPACE CITY**  
   基本ステージ。広大な空間での基本操作と敵パターンへの適応。
2. **STAGE 2: ASTEROID FIELD**  
   障害物（小惑星）が浮遊する危険地帯。
3. **STAGE 3: CAVE TUNNEL**  
   チューブ状の洞窟ステージ。シード値によってダイナミックに生成される複雑な壁面に注意。

**【周回 (LOOP) システム】**  
STAGE 3 をクリアするとゲームは周回（LOOP 2, LOOP 3 ...）へ突入します。周回ごとに敵の移動速度・射撃頻度・弾速・ボスHPが強化され、より歯ごたえのある難易度へスケールアップします。

## アイテムとパワーアップ

特定の敵を撃破するか、画面奥から流れてくるアイテムを取得することで自機を強化・回復できます。自機が近づくと自動的に磁力吸い寄せ（マグネット）が働きます。

- **HEAL (ピンク/ハート型)**: ライフ（HP）回復
- **BULLET (シアン/クリスタル型)**: 弾薬補充
- **POWERUP (マゼンタ/キューブ型)**: ショット強化 (Lv1: シングル ➔ Lv2: ツイン ➔ Lv3: 3方向スプレッド)
- **BARRIER (ゴールド/星型)**: 一定時間（10秒間）無敵状態になるバリアを展開

---

## 敵キャラクター

- **TYPE-A (Straight)**: 直線的に前進してくる基本敵。
- **TYPE-B (Zizgag)**: 左右にジグザグ蛇行しながら進軍する敵。
- **TYPE-C (Charger)**: 自機に向かって高速で直線突撃してくる特攻敵。
- **TYPE-D (Shooter)**: 一定距離で停止し自機へ弾を発射する射撃敵。
- **TYPE-E (Sniper)**: 遠距離で停止し高精度の狙撃弾を連射後、後退する敵。
- **TYPE-F (Helix)**: 螺旋（サインカーブ）を描きながら進軍するトリッキーな敵。
- **BOSS**: 複数フェーズと段階的な弾幕攻撃パターンを持つ超大型要塞。
