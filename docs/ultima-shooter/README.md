# Ultima Shooter (v0.1.2)

Webブラウザ上で動作する、Three.js を用いた 3D 縦スクロールシューティングゲームです。

© 2026 Ultima Architect Inc.

---

## 概要

HTML / CSS / JavaScript、Three.js (r128)、および Web Audio API を使用して構築されています。  
外部のビルドツール（Node.js / Webpack 等）やローカルサーバーは不要で、ES Modules を使わない依存順読み込み構成のため、`src/index.html` をブラウザ（Google Chrome, Firefox, Edge 等）で直接開くだけですぐにプレイできます。

---

## 主な特徴

- **ピュアフロントエンド（非ビルド・ローカル実行対応）**: ES Modules 不使用の生 JavaScript (ES6+) 構成。`index.html` を開くだけで即時起動。
- **責務分離されたモジュールアーキテクチャ**: `Game` をオーケストレーターとし、`EntityManager` / `CollisionManager` / `UIManager` / `DebugManager` / `ScoreManager` / `TouchController` 等に責務を分割した高い保守性・拡張性。
- **ポストプロセッシング & カスタムシェーダー演出**: Three.js の `UnrealBloomPass`（ネオン発光）、FXAA アンチエイリアス、カスタムシェーダー（被弾ダメージフラッシュ・色収差・空間歪み）、衝撃波リング・高密度スパークパーティクルを搭載。
- **レスポンシブ & モバイルブラウザ対応**:
  - 狭幅・縦長画面では水平視界を維持するようカメラの垂直 FOV を自動拡張（通常 16:9 等のデスクトップ画面は基準 FOV 72° を維持）。
  - 画面サイズ・セーフエリアに応じたレスポンシブ UI スケール調整。
  - タッチデバイス向けに、仮想アナログジョイスティック・`FIRE`・`AUTO` 連射切替・`PAUSE` ボタンを自動表示。
- **Web Audio API プロシージャルサウンド**: 効果音・BGM をプログラム処理でリアルタイム合成。
- **周回（ループ）システム**: 全 3 ステージをクリアすると難易度とゲーム進行速度が上昇した状態で次の周回（LOOP）へ突入。
- **プロシージャル洞窟生成**: シード値に基づくチューブ状の洞窟地形を動的に生成し、壁面との衝突・バウンド判定を処理。
- **ローカルランキング機能**: `localStorage` にハイスコア TOP 10（スコア・名前・周回数・ステージ・日時）を永続化。
- **高パフォーマンス設計**: ObjectPool による弾・敵・アイテム・障害物・パーティクルの再利用と、可変 FPS / デルタタイム（上限キャップ付き）による安定したゲーム速度。
- **充実のデバッグパネル**: タイトル画面の「DEBUG PANEL」からステージ選択、周回数変更、洞窟シード指定、無敵モード、最大パワー、即時ボス戦、ボス撃破キー、FPS 表示等を設定可能（チート有効時はスコア記録を自動無効化）。

## 遊び方

### 起動方法

1. 本リポジトリをローカルにクローンまたはダウンロードします。
2. `src/index.html`（またはビルド済みの `dist/index.html`）をブラウザで直接開いてください。

### 配布パッケージのビルド（任意）

Windows 環境では以下のスクリプトを実行すると、`src/` 一式と `LICENSE` / `README.md` をまとめたリリース用パッケージを `dist/` に出力できます。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

## 操作方法

本ゲームは **キーボード**、**ゲームパッド（XInput 対応コントローラー等）**、および **タッチ操作（モバイルブラウザ）** に対応しています。

### キーボード操作

- **`↑` `↓` `←` `→`** または **`W` `A` `S` `D`**: 自機の移動
- **`Space`**: ショット発射（押しっぱなし連射） / メニュー決定
- **`Enter`**: メニュー決定
- **`Esc`**: ポーズ / ポーズ解除 / モーダルキャンセル

### ゲームパッド操作

- **左スティック** または **十字キー (D-Pad)**: 自機の移動 / メニューフォーカス移動
- **A ボタン** または **RT (R2)**: ショット発射 / メニュー決定
- **B ボタン**: モーダルキャンセル
- **START ボタン**: ゲーム開始 / ポーズ / ポーズ解除

### タッチ操作（モバイルブラウザ）

タッチ対応端末でプレイを開始すると、画面上にタッチコントローラーが自動表示されます（マルチタッチ対応）。

- **画面左下（仮想アナログジョイスティック）**: 自機の移動（指を離すと中央復帰）
- **画面右下（`FIRE` ボタン）**: ショット発射（押しっぱなし連射）
- **画面右下（`AUTO` ボタン）**: オートショットの ON / OFF 切替
- **画面右上（`II` ボタン）**: ポーズ / ポーズ解除

## ステージ構成 & 周回システム

全 3 ステージで構成され、各ステージで一定距離の進行と敵撃破ポイント（POINT）を達成するとボス戦へ突入します。ボスを撃破するとステージクリアです。

1. **STAGE 1: Grasslands**（ボス: `GREEN TITAN`）  
   基本ステージ。広めの洞窟空間で基本操作と敵ウェーブに適応。
2. **STAGE 2: Ocean**（ボス: `BLUE LEVIATHAN`）  
   障害物（浮遊岩）の増加と狙撃型の敵が登場する中盤ステージ。
3. **STAGE 3: Void Cave**（ボス: `VOID OVERLORD`）  
   急激な狭窄や激しいうねりを持つ高難度洞窟ステージ。

> [!NOTE]
> **周回 (LOOP) システム**: STAGE 3 をクリアすると周回数（LOOP 2, LOOP 3 ...）がインクリメントされ、敵の移動速度・出現頻度・弾速・ボス HP・ゲーム進行速度がスケールアップした状態で STAGE 1 から継続します。

## アイテムとパワーアップ

敵撃破時のドロップや空間上から出現するアイテムを取得することで自機を強化・回復できます。一定距離に近づくと自動で吸い寄せ（マグネット）が働きます。

- **HEAL（レッド / ハート型）**: ライフ（HP）回復
- **BULLET（シアン / クリスタル型）**: 弾薬補充
- **POWERUP（マゼンタ / キューブ型）**: ショット強化（Lv.1: シングル → Lv.2: ツイン → Lv.3: 3方向スプレッド）
- **BARRIER（イエロー / 星型）**: 一定時間（10秒間）無敵バリアを展開し、敵への体当たり撃破が可能

## 敵キャラクター

- **TYPE-A (Straight)**: 直線的に前進してくる基本敵。
- **TYPE-B (Zizgag)**: 左右にジグザグ蛇行しながら進軍する敵。
- **TYPE-C (Charger)**: 自機に向かって高速で直線突撃してくる特攻敵。
- **TYPE-D (Shooter)**: 一定距離で停止し自機へ弾を発射する射撃敵。
- **TYPE-E (Sniper)**: 遠距離で停止し高精度の狙撃弾を連射後、後退する敵。
- **TYPE-F (Helix)**: 螺旋を描きながら進軍するトリッキーな敵。
- **BOSS**: 複数フェーズ・段階的弾幕・極太ビーム攻撃を持つ大型要塞。
