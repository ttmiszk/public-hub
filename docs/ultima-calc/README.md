# Ultima Calc

ブラウザーで動作する高機能電卓アプリです。HTML・CSS・JavaScriptを単一HTMLファイルにまとめているため、ビルドやサーバー、外部ライブラリは必要ありません。

## 使い方

1. `index.html` をダウンロードまたはリポジトリから取得します。
2. ファイルを対応ブラウザーで開きます。
3. 数式を入力して Enter キーまたは「計算 =」を押します。

インターネット接続は不要、完全にオフラインで動作します。

### アプリモード（PWAライク）での起動（Windows 11 / 10）

アドレスバーやタブバーを非表示にし、電卓アプリ専用ウィンドウとして起動できます。タスクバーへのピン留めも可能です。

1. **ショートカットの作成**:
   - デスクトップ等の任意の場所で右クリック →「新規作成」→「ショートカット」を選択。
   - 「項目の場所」に以下のように入力します（黒いコンソール画面を出さずに起動します）:
     ```text
     powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "絶対パス\launch.ps1"
     ```
     ※ デフォルトでは位置移動なし（前回の位置を維持）、サイズ **640×900** で起動します。
     ※ オプション引数の指定例:
     - 画面中央に配置したい場合: 末尾に `-Center` を付加
     - Google Chrome で起動したい場合: 末尾に `-Browser Chrome` を付加
     - サイズを変更したい場合: `-Width 500 -Height 800` などを付加
     - 例（Chromeで画面中央に配置）:
       ```text
       powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "絶対パス\launch.ps1" -Browser Chrome -Center
       ```
2. **アプリアイコンの設定**:
   - 作成したショートカットを右クリック →「プロパティ」を開きます。
   - 「ショートカット」タブの「アイコンの変更」ボタンを押し、プロジェクト内にある `app.ico`（または `favicon.ico`）を選択します。
3. **タスクバーへのピン留め**:
   - ショートカットを右クリックして「タスクバーにピン留めする」を選択すると、タスクバーから直接ワンクリックで専用電卓アプリとして起動できます。

## 機能

- **標準／拡張モード**：標準モードでは四則演算を中心に表示し、拡張モードでは科学計算キーを表示します。
- **数式計算**：括弧、負数、小数、四則演算、整数の剰余、べき乗、階乗に対応します。
- **科学計算**：三角関数と逆関数、対数、指数、平方根、立方根、絶対値、π、eに対応します。角度計算はラジアン（RAD）です。
- **ANSとメモリー**：直前の計算結果と、M+ / M− / MR / MCによるメモリーを利用できます。
- **履歴**：直近100件を表示し、式の再利用、個別コピー、個別削除、全件コピー、全件削除ができます。
- **単位換算**：長さ、重さ、面積、体積、データ容量、角度（rad / deg）を変換できます。
- **日付計算**：2日付間の日数と、日付への日数加算・減算を計算できます。
- **進数変換**：2進数、8進数、10進数、16進数の符号付き整数を相互変換します。
- **表示設定**：ライト／ダークテーマを切り替え、履歴とツールペインを個別に表示・非表示にできます。

履歴、ANS、メモリーはページを閉じるか再読み込みすると初期化されます。データの保存や外部通信は行いません。

## 数式の書き方

数値、`+`、`-`、`*` / `×`、`/` / `÷`、`%`、`^`、括弧、定数 `pi` / `π`、`e`、`ANS` を使用できます。関数は1つの引数を括弧で囲みます。

```text
2 + 3 * 4       → 14
(2 + 3) * 4     → 20
0.1 + 0.2       → 0.3
-2^2            → -4
sin(pi / 2)     → 1
sqrt(9)         → 3
5!              → 120
```

べき乗は右結合です（`2^3^2` は `2^(3^2)`）。べき乗は単項マイナスより優先されるため、`-2^2` は `-(2^2)` です。暗黙の乗算（`2pi` や `2(3+4)`）は使えません。`2*pi`、`2*(3+4)` のように `*` を入力してください。階乗と剰余は整数を対象とします。

数式は許可されたトークンを字句解析して評価します。`eval()` や `Function()` によるコード実行は使用しません。

## 数値の精度

四則演算はBigIntを使った10進係数と小数桁数で処理します。加算・減算・乗算では、通常の有限小数入力を2進浮動小数点に変換せずに扱います。除算は小数点以下18桁で四捨五入し、末尾のゼロを表示しません。三角関数、対数、指数などの科学関数と単位換算はJavaScriptの倍精度 `Number` を使います。

## 保守・拡張の手引き

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体。HTML、スタイル、計算処理、UI制御を内包 |
| `launch.ps1` | Windows用アプリモード起動＆自動リサイズランチャースクリプト |
| `app.ico` / `favicon.ico` | Windows用ショートカットアイコンおよびFaviconリソース |
| `README.md` | 利用方法と実装仕様 |
| `LICENSE` | ライセンス（MIT License） |

外部CDN、フォント、画像、APIへの依存はありません。ブラウザー標準機能とBigIntを利用します。

### コードの構成

JavaScriptは末尾のIIFE内にあり、アプリの状態や関数をグローバルスコープへ公開しません。

- **`Decimal`**：10進係数・スケールを保持する四則演算の値型です。除算の桁数や丸め方を変更する場合は、`DIV_SCALE` と `Decimal.div()` を合わせて見直してください。
- **`tokenize()` / `parseExpression()`**：数式を字句解析し、許可された構文だけを評価します。演算子の優先順位は `parseExpression()`、演算の実装は `operate()` にあります。
- **`factorial()` / `applyFn()`**：階乗と科学関数を処理します。科学関数のドメイン確認とRADの扱いもここで行います。
- **履歴・入力・画面制御**：`renderHistory()`、`evaluate()`、入力イベント処理などが担当します。ユーザー由来の文字列はDOMの `textContent` 等で表示してください。
- **単位換算**：`unitSets` に各カテゴリの基準単位に対する係数を定義します。角度はradを基準単位とし、degは `Math.PI / 180` radです。
- **日付計算**：`dateParts()` で日付をUTCの暦日として扱い、タイムゾーンや夏時間による日数差を避けます。
- **進数変換**：`convertBase()` は整数の検証と変換にBigIntを使います。

### 変更時の確認項目

変更後はファイルをブラウザーで開き、少なくとも次を確認してください。

1. `2 + 3 * 4`、`(2 + 3) * 4`、`0.1 + 0.2`、`-2^2`、`2^3^2`。
2. 拡張モードで `sin(pi / 2)`、`asin(1)`、`sqrt(9)`、`log(100)`、`5!`。
3. `1 / 0`、`sqrt(-1)`、未知の関数などで、分かりやすいエラーが出て以前のANSが保たれること。
4. ANS、メモリー、履歴のコピーと再利用、100件上限、ページ再読み込み後の初期化。
5. `1 km → m`、`1 KiB → B`、`180 deg → rad`、うるう日をまたぐ日数、`255 → FF`。
6. 標準／拡張、履歴・ツールの表示切替、ライト／ダーク、狭い画面でのレイアウト。

計算エンジンに新しい構文を追加するときは、字句解析・パーサー・エラー条件を一緒に更新し、任意コード実行に到達しないことを確認してください。数値演算を変更する場合は、表示用整形だけで誤差を隠さず、内部値と表示精度の両方を確認してください。
